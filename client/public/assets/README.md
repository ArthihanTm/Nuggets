# assets/

Leg hier dein Sprite-Sheet als `player.png` ab (Frame-Größe standardmäßig
32×48 px, Layout und Frame-Zuordnung in
`client/src/scenes/GameScene.ts` ganz oben einstellbar).

Ohne diese Datei zeichnet das Spiel Spieler weiterhin als einfache farbige
Rechtecke — das Projekt läuft also auch ohne Sprite-Sheet einwandfrei,
diese Datei ist rein optional fürs Aussehen.
